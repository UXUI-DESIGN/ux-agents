1

데이터 선택

페르소나의 바탕이 될 인터뷰를 고르세요. 같은 서비스에 대한 인터뷰끼리 묶는 것이 좋아요.

옵션

페르소나 유형
생성 개수

생성

  1. 1분석 중인터뷰 기록에서 패턴 추출

  3. 3이미지 생성문서에서 프롬프트 확인 후 생성
  4. 4완료문서 열기
